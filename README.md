This is a Python-based 3D parking game featuring multiple car models, different camera views, headlights, interactive doors, collision detection, scoring, and four parking levels. Players use keyboard and mouse controls to drive, steer, change camera views, and complete parking challenges.


| Key               | Action                             |
| ----------------- | ---------------------------------- |
| **↑ Up Arrow**    | Drive forward                      |
| **↓ Down Arrow**  | Reverse / brake                    |
| **← Left Arrow**  | Steer left                         |
| **→ Right Arrow** | Steer right                        |
| **C**             | Switch camera view                 |
| **H**             | Toggle headlights                  |
| **J**             | Toggle doors                       |
| **V**             | Change car model                   |
| **R**             | Restart current level              |
| **T**             | Restart the entire game            |
| **SPACE**         | Start game / proceed to next level |
| **ESC**           | Exit game                          |
